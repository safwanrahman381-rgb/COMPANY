Product images live here, named after the product's slug in data/products.json,
e.g. `tretinoin-cream-0-1-20g.jpg` (.jpg, .jpeg, .png or .webp, square, ideally 1200×1200).

The JPGs currently here are generated placeholders. Replace each one with a real photo
of the product, keeping the same file name. A product without a file here gets an
automatically generated placeholder image.
