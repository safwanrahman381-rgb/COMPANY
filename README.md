# BLACKLINE marketing engine (Claude Code)

## Setup (once, no Claude Code usage)
1. Unzip this folder somewhere, open it in VS Code / terminal.
2. `pip install playwright && python -m playwright install chromium`
3. Look at `marketing/examples/style-test/` - that's the house carousel style. Happy? Skip the style run.

## Spending your Claude Code runs well
- Run 1: `/blackline-content week` (after filling `marketing/inputs/this-week.md`) -> 12 drafts + rendered slides.
- Run 2: next week, same command. Edit drafts yourself instead of asking Claude for small tweaks.
- Run 3: after ~4 weeks with metrics filled in `post-log.md`: `/blackline-content review`.
- Keep 1 spare for a fix.

## Weekly routine (~30 mins of your time)
1. Fill `this-week.md` (voice note transcript is fine).
2. Run the week. Fix anything on a NEEDS line (photos, real numbers).
3. Schedule in GoHighLevel Social Planner. Post LinkedIn from your personal profile.
4. Reply to every comment within the first hour. DM anyone who comments a keyword.
5. 7 days later, fill the metrics in `post-log.md`.
