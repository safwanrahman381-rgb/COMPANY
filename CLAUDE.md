# Working rules

## BLACKLINE marketing
- All marketing work uses the `blackline-content` skill in `.claude/skills/blackline-content/`.
- Usage is limited: do one full week per run, write to files, keep chat replies to 5 lines, no web research unless asked to "refresh trends".
- Never post or schedule anything. Drafts only; Safwan approves.
- Never invent results, clients, testimonials or numbers.

## Usage
- Don't spawn agents for tasks that take a few direct tool calls. Delegate only bulk or mechanical work to Sonnet or Haiku subagents.
- Don't search past chats, old sessions or Notion/Drive history unless the task names something specific to find.
- Ask for missing inputs in one short question instead of hunting for them.
- Put long deliverables in a doc or file, not in chat.

## Meta ads
- Follow the `meta-ads-playbook` skill for any ad, funnel or creative work.
- Use [placeholders] for unknown figures.
- New campaigns launch paused. Ask before anything that spends money.
